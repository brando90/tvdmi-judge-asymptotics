# theory

This directory contains the mathematical core of the project:

- problem setup
- assumptions
- theorem statements
- proof sketches in natural language

The main asymptotic variable is **K**, the number of judges.
The main sample-size variable is **n**, the number of evaluated items.
Secondary variables include **m** for pairwise comparison density,
**rho** for judge dependence, and **delta** for adversarial contamination.
